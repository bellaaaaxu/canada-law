# M1（BC 跑通）实施计划

> 执行方式：同一会话内按任务顺序 TDD（先写失败的测试 → 实现 → 跑通）。当时项目放在一个不能建 git 的工作目录里，所以没有 commit 步骤。

**目标：** 本地 MCP 服务器，4 个 BC 工具 + `map_term`，每条结果带官方出处和「现行至」日期；golden 前三条在 `search_law` 前 5 条里命中。

**架构：** `http.ts`（带 24 小时磁盘缓存的抓取）→ `sources/`（CiviX 地址、XML/HTML 解析、搜索结果分类与排序）→ `tools/`（每个工具一个文件）→ `server.ts`（注册工具与 instructions）→ `index.ts`（stdio 入口）。抓取函数可注入，单元测试用 2026-09-24 抓下的真实返回做离线样本；golden 与术语表核对走线上。

**技术栈：** TypeScript（ESM / NodeNext）、Node 24、`@modelcontextprotocol/sdk`、`zod`、`fast-xml-parser`（preserveOrder 模式，保留混排文本）、vitest、tsx。

## 实测得出、代码必须照做的规则（详见 SPEC「BC Laws」一节）

| 规则 | 来源 |
|---|---|
| fullsearch 每次 ≤20 条；查询整体加括号 | 实测 e−s>20 → 500；不加括号第一个词变可选 |
| 按 `CIVIX_DOCUMENT_LOC` 分类：`00_xxx.xml`＝单文件法案，`00_Act/`＝多文件法案的一个 Part，`NN_Regulations/`＝条例，其余（TLC、Historical Table、Point in Time）丢掉 | 实测 7 组搜索结果 |
| 多文件法案：act_id 用 `{前缀}_00_multi`（取 XML 用），网页用 `{前缀}_00`；条的链接在 Part 页上 | `02057_00/xml` 返回的是 HTML 目录页（`data-ismulti="true"`） |
| 文档内搜索零命中时服务器返回 500 → 记 warning，不当成「没有」 | 实测 ESA 搜 xylophone → 500 |
| xpath 条号不存在 → 200 + `No Results` | 实测 s.999 |
| 同一条号可能出现多次（正文与 Schedule 各有 s.1）→ 全部返回并警告 | 实测 LGA |
| current_to 读官方网页那一行，转成 ISO 日期；读不到返回 null + warning | Act 与 Regulation 规则不同 |
| 已废止/被取代的法案：XML 有 `act:repealedtext`（0 条）→ 如实说明 | 实测 96492_00、96191rep_01 |
| 定义词在官方网页上带直引号：`"statutory holiday" means …` | 官方 HTML |

## 文件

```
src/index.ts              stdio 入口
src/server.ts             createServer({ fetcher, glossary }) → McpServer
src/http.ts               cachedFetch：UA、24 小时磁盘缓存（只缓存 200）、返回 fetchedAt
src/types.ts              Citation 等共享类型
src/glossary.ts           读术语表、查词
src/sources/bc-xml.ts     XML → 节点树；找条、渲染条文、目录、命中分析
src/sources/bc-meta.ts    网页 → 标题 / citation / current_to；搜索结果 LOC → 分类与 citation
src/sources/bc.ts         CiviX 客户端：拼地址、抓取、解析、多文件与废止判断、排序
src/tools/*.ts            find-act / get-toc / get-section / search-law / map-term
data/glossary.json        BC 词条约 30 条
scripts/verify-glossary.ts  线上核对：每个英文词确实出现在所写的条里
scripts/golden.ts         线上 golden：经 stdio 连 dist/index.js，按「命中」算法判定
tests/fixtures/           2026-09-24 抓下的真实返回
tests/*.test.ts           单元测试（离线）
tests/golden.jsonl
```

## 任务

1. **脚手架**：package.json、tsconfig、.gitignore；装依赖；把实测样本存进 `tests/fixtures/`。
2. **http.ts**：测试——第二次取同一 URL 走缓存且 `fetchedAt` 不变；超过 24 小时重新抓；非 200 不缓存；请求带 UA。
3. **bc-xml.ts**：测试——ESA s.40 渲染出 `40 (1) An employer must pay…`、`(a) 1 1/2 times…`、`(4) [Repealed 2002-42-19.]`；s.999 → 无；s.1 含 `"statutory holiday" means New Year's Day,`；修订标记去掉但文字不丢（`74 (5), 76 (2), (3) or (8), 79`）；目录 14 个 Part、Part 4 标题与 s.40 标题；多文件样本里 s.10 属于 `02057_02`；命中分析：s.40 标题命中且以命中词开头，s.1「statutory holiday」是完整定义词。
4. **bc-meta.ts**：测试——ESA 网页 → `RSBC 1996, c. 113`、`2026-09-15`；ESR 网页 → `2026-09-22`；没有那一行 → null；LOC 分类与 citation（含多文件 Part、条例 `B.C. Reg. 396/95`、丢弃 TLC/PIT/HT）。
5. **bc.ts**：用假抓取函数测——find_act 合并多文件 Part、精确标题排第一；get_section 找不到时报错并提示用 get_toc；search_law 两步走，overtime 样本里 s.40 进前 3、statutory holiday 样本里 s.1 第 1；文档内搜索 500 → warning。
6. **glossary.ts + map_term**：测试——中文精确、英文精确、问句里包含词条、找不到返回 `[]`。
7. **server.ts + tools + index.ts**：内存客户端测试——列出 5 个工具、描述是英文、instructions 在；federal 返回「M2 才支持」。
8. **glossary.json + verify-glossary**：约 30 条 BC 词条，线上逐条核对全部通过才算数。
9. **golden**：`tests/golden.jsonl` 4 行；`npm run golden` 构建后经 stdio 跑，BC 三条都在前 5 条。
10. **注册**：`claude mcp add canada-law -- node <绝对路径>/dist/index.js`；`claude mcp list` 显示已连接。
11. **收尾**：勾 SPEC 里的 M1 清单、更新 memory、汇报。
