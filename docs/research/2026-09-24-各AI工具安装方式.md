# 各 AI 工具怎么装 skill 和本地 MCP（2026-09-24 查官方文档）

> 只记官方文档写明的内容。每条后面的字母对应文末的链接。写 README 时照这里写；标「未写明」的，README 里就不写。

## Skill 放在哪

| 工具 | 用户级（全局） | 项目级 | 备注 |
|---|---|---|---|
| Claude Code | `~/.claude/skills/<名字>/SKILL.md`（Windows：`%USERPROFILE%\.claude`）(a)(b) | `.claude/skills/` (a) | 脚本可引用为 `${CLAUDE_SKILL_DIR}/scripts/…`（只有 Claude 认），`allowed-tools` 可免权限提示 (a)。需要 Pro/Max/Team/Enterprise/Console，免费版不行 (c) |
| Claude 桌面版 | Code 标签页读 `~/.claude/skills/`；Cowork / Chat 用 claude.ai 账号里的 skills (d) | 同 Claude Code (d) | |
| claude.ai | 打成 zip（文件夹在 zip 根目录、名字和 skill 名一致）→ Customize > Skills > + > Upload a skill (e)(f) | — | 脚本在 Anthropic 的容器里跑，能否联网取决于「Allow network egress」等设置 (h)。**帮助中心写 description 最多 200 字符 (f)**，平台文档写 1024 (g) |
| OpenAI Codex（CLI、IDE 扩展、ChatGPT 桌面版） | `$HOME/.agents/skills` (i) | `.agents/skills`（当前目录到仓库根的每一层）(i) | ChatGPT 网页版只能通过插件 (i)。新 skill 没出现就重启 (i) |
| GitHub Copilot / VS Code | `~/.copilot/skills/`、`~/.claude/skills/`、`~/.agents/skills/` (l) | `.github/skills/`、`.claude/skills/`、`.agents/skills/` (l) | **脚本必须在 SKILL.md 里用 Markdown 链接或 `#file:` 引用 (l)** |
| Cursor | `~/.agents/skills/`、`~/.cursor/skills/`，也读 `~/.claude/skills/`、`~/.codex/skills/` (p) | `.agents/skills/`、`.cursor/skills/`，也读 `.claude/skills/` (p) | 脚本任何语言都行 (p) |
| Gemini CLI | `~/.gemini/skills/` 或 `~/.agents/skills/` (q) | `.gemini/skills/` 或 `.agents/skills/` (q) | 可用 `gemini skills install <git 地址或本地目录>` (q)。**免费版和 Google One 用户 2026-06-18 起已换成 Antigravity CLI** (t)(u) |

**结论（由上表推出）**：放两个文件夹就几乎全覆盖——`~/.claude/skills/`（Claude Code、VS Code、Cursor）+ `~/.agents/skills/`（Codex、VS Code、Cursor、Gemini CLI）。另有 `gh skill install OWNER/REPO SKILL --agent claude-code --scope user`（GitHub CLI 2.90+，预览版）自动放到对应目录 (n)。

## 本地 MCP 服务器（`node /路径/canada-law-mcp.mjs`）

| 工具 | 怎么加 | 来源 |
|---|---|---|
| Claude Code | `claude mcp add --scope user canada-law -- node /路径/canada-law-mcp.mjs` | (a) |
| Claude 桌面版 | Settings > Developer > Edit Config，编辑 `claude_desktop_config.json`（macOS `~/Library/Application Support/Claude/`，Windows `%APPDATA%\Claude\`），写 `{"mcpServers":{"canada-law":{"command":"node","args":["绝对路径"]}}}`，完全退出再开。**或者装 `.mcpb` 扩展：自带 Node.js，不用另装** | (v)(w)(x) |
| claude.ai 网页 / 手机 | **不支持本地服务器**，只能用放在网上的远程服务 | (y)(z) |
| Codex | `codex mcp add canada-law -- node /路径/canada-law-mcp.mjs`，或 `~/.codex/config.toml` 写 `[mcp_servers.canada-law]` / `command = "node"` / `args = ["/路径"]` | (aa) |
| VS Code / Copilot | `code --add-mcp "{\"name\":\"canada-law\",\"command\":\"node\",\"args\":[\"/路径\"]}"`，或 `.vscode/mcp.json`（`servers` 键）。Copilot Business/Enterprise 要管理员开「MCP servers in Copilot」策略（默认关） | (ac)(ad)(ae) |
| Cursor | `~/.cursor/mcp.json` 或 `.cursor/mcp.json`，`{"mcpServers":{"canada-law":{"command":"node","args":["/路径"]}}}` | (af) |
| Gemini CLI | `gemini mcp add -s user canada-law node /路径/canada-law-mcp.mjs`（名字不能有下划线） | (ai) |

名字 `canada-law`：Claude Code 和 Gemini CLI 文档都允许连字符；VS Code 只是「建议」驼峰写法，是否影响没写明 → VS Code 标「未实测」。

## 官方文档之间对不上的地方

1. claude.ai 的 skill：帮助中心 (e)(f) 说免费版也能用、description 限 200 字符、文件叫 `skill.md`；平台文档 (g) 说付费版、1024 字符、`SKILL.md`。**description 控制在 200 以内就都满足。**
2. Claude 桌面版手动配置文件的路径只写在 modelcontextprotocol.io (v)，Anthropic 帮助中心 (w) 只讲 `.mcpb` 扩展。
3. Codex 在 Windows 上 `~/.agents/skills` 的位置没写明。
4. VS Code 字段表说 `type` 必填，但 stdio 示例都省略；Cursor 同样。

## 官方校验工具 skills-ref

- 需要 Python 3.11+；官方 README 说明「仅供演示，不用于生产」(skills-ref)
- **中文 Windows 上要先设 `PYTHONUTF8=1`**，否则它用 GBK 读 SKILL.md，遇到中文直接崩溃（2026-09-24 实测）
