# 第二批 AI 工具：skill 和本地 MCP 怎么装（2026-09-25 查官方文档）

> 只记官方文档（官网文档、官方 GitHub 仓库）写明的内容。字母编号对应文末链接。写安装器和 README 时照这里写。

## 先说结论

| 工具 | 建议 | 理由 |
|---|---|---|
| GitHub Copilot CLI | ✅ 加 | 有官方命令 `copilot mcp add`；skill 读 `~/.agents/skills/`；「所有 Copilot 方案都能用」(H4) |
| Antigravity（谷歌） | ✅ 加 | **官方写明支持加拿大**，有免费方案 (G5)(G6)；Gemini CLI 免费用户就是被换到这里；skill 和 MCP 位置都写明了 |
| Kiro（亚马逊） | ✅ 加 | 有免费额度，加拿大可付费 (KR4)(KR5)；skill 和 MCP 位置都写明了 |
| Qwen Code（阿里） | ✅ 加 | 有官方命令 `qwen mcp add`；**免费额度 2026-04-15 已结束，现在要付费** (Q4) |
| OpenCode | ✅ 加（标注） | skill 读 `~/.agents/skills/`、`~/.claude/skills/`；**skill 能不能运行脚本，文档没写** (O1) |
| Kimi Code CLI | ✅ 加 | skill 读 `~/.agents/skills/`；MCP 文件位置写明了；需要 Kimi 付费会员，加拿大是否可用没写 (K6) |
| Cline | ◐ 只装 skill | 官方文档里 MCP 配置文件位置有三种说法，互相矛盾 (C2)(C3)(C4) → 让用户用它自己的向导 `cline mcp` |
| DeepSeek Harness（`dsh`） | ◐ 只装 skill | DeepSeek 官方产品，但是开发预览版，明说「会有不兼容的改动」(D1)；skill 读 `~/.agents/skills/`，自动覆盖 |
| Trae（字节） | ❌ 不加 | **官方支持国家列表里没有加拿大**，付费版在加拿大不卖 (T4)(T5)；国际版用户级 MCP 路径没写明 (T2)；命令行版只在国内文档、只给企业旗舰版 (T9)(T12) |
| Reasonix | ❌ 不加 | 不是 DeepSeek 官方产品，是个人开发者的项目，DeepSeek 只把它列为「集成」(R1)(R2) |
| Kimi CLI（旧版） | ❌ 不加 | 仓库已归档、「不再维护」，由 Kimi Code CLI 接替 (K1)(K7) |

**一个文件夹覆盖一大片**：`~/.agents/skills/` 被 Codex、VS Code / Copilot、Cursor、Gemini CLI（第一批）和 Copilot CLI、OpenCode、Kimi Code、DeepSeek Harness（第二批）共同读取。需要各自文件夹的：Antigravity、Kiro、Qwen Code、Cline。

## Skill 放在哪（用户级）

| 工具 | 用户级目录 | 项目级目录 | 能运行脚本 |
|---|---|---|---|
| Copilot CLI | `~/.copilot/skills/`、`~/.agents/skills/`；也可 `copilot skill add <路径>` (H1) | `.github/skills/`、`.agents/skills/`、`.claude/skills/` (H1) | 能 (H3) |
| Antigravity | 2.0 和 IDE：`~/.gemini/config/skills/`；**CLI（`agy`）：`~/.gemini/antigravity-cli/skills/`** (G1) | `.agents/skills/` (G1) | 能 (G1) |
| Kiro | `~/.kiro/skills/` (KR1) | `.kiro/skills/` (KR1) | 能 (KR1) |
| Qwen Code | `~/.qwen/skills/` (Q1) | `.qwen/skills/` (Q1) | 能 (Q1) |
| OpenCode | `~/.config/opencode/skills/`、`~/.claude/skills/`、`~/.agents/skills/` (O1) | `.opencode/skills/`、`.claude/skills/`、`.agents/skills/` (O1) | **没写明** |
| Kimi Code CLI | `~/.kimi-code/skills/`、`~/.agents/skills/` (K2)(K4) | `.kimi-code/skills/`、`.agents/skills/` (K2) | 能 (K2) |
| Cline | `~/.cline/skills/`（另一页写 `~/.cline/data/settings/skills/`，矛盾）(C1)(C4) | `.cline/skills/`、`.clinerules/skills/`、`.claude/skills/` (C1) | 能 (C1) |
| DeepSeek Harness | `~/.dsh/skills`、`~/.agents/skills` (D3)(D4) | `.dsh/skills`、`.agents/skills` (D3) | 能 (D3) |

`canada-employment-law` 这个名字符合以上所有工具的命名规则；OpenCode、Kiro、Cline 要求 `name` 和文件夹名一致。

## 本地 MCP 怎么加

| 工具 | 方式 | 来源 |
|---|---|---|
| Copilot CLI | `copilot mcp add canada-law -- node /路径/canada-law-mcp.mjs`（写进 `~/.copilot/mcp-config.json`） | (H1)(H2) |
| Antigravity | 没有添加命令；编辑 `~/.gemini/config/mcp_config.json`（CLI 和 IDE 共用），格式 F1。另可 `agy plugin install <目录>` 装一个同时带 MCP 配置和 skills 的插件 | (G1)(G2)(G3) |
| Kiro | 编辑 `~/.kiro/settings/mcp.json`（IDE 和 CLI 共用），格式 F1；IDE 还要打开「MCP support」设置。`kiro-cli mcp add` 的 `--args` 参数两页文档说法不一，**不用命令、改文件** | (KR2)(KR3) |
| Qwen Code | `qwen mcp add --scope user canada-law node /路径/canada-law-mcp.mjs`（写进 `~/.qwen/settings.json`） | (Q2) |
| OpenCode | 编辑 `~/.config/opencode/opencode.json`，格式 F3（`opencode mcp add` 是交互式的） | (O2)(O3)(O4) |
| Kimi Code CLI | 编辑 `~/.kimi-code/mcp.json`，格式 F1（没有非交互的添加命令） | (K3)(K5) |
| Cline | 不自动写；README 请用户运行 `cline mcp` 向导 | (C2) |
| DeepSeek Harness | 不自动写（YAML 补丁文件，开发预览版随时会变） | (D5) |

**格式**
- F1：`{"mcpServers":{"canada-law":{"command":"node","args":["/路径/canada-law-mcp.mjs"]}}}`
- F3：`{"$schema":"https://opencode.ai/config.json","mcp":{"canada-law":{"type":"local","command":["node","/路径/canada-law-mcp.mjs"],"enabled":true}}}`

## 官方文档之间对不上的地方
1. Cline：MCP 文件位置三种说法；全局 skill 位置两种说法 (C1)–(C4)
2. Kiro：`kiro-cli mcp add` 是否有 `--args` 参数，两页不一致 (KR2)(KR3)
3. Copilot：skill 的 `name` 一页说「必须小写」，另一页说「字母、数字、连字符」(H1)(H3)
4. Trae：国际版示例链接里多了一个空格 (T3)
